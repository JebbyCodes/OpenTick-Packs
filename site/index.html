Sections and themes for OpenTick, made by people like you

A pack is a small file that adds a ready-made section (a reading list, a plant journal, a study planner…) or a set of colours to your OpenTick. Every pack has a code.

    Made something good?

    Build a section in OpenTick, export it from Settings → Sections & packs, and send it here as a pull request. It is checked automatically (including how it affects OpenTick’s speed) and reviewed before it is published. How to send one →

    Packs are data only: sections, entries and colours. They contain no code and cannot read anything you have in OpenTick, and you see what is inside before anything is added. Each pack has its own licence, shown on its page.
