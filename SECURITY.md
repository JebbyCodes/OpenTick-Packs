# Security

A pack is **data**: sections, entries and colours. OpenTick reads it with strict checks (it keeps only what the pack format names, cuts everything to size, and refuses anything else), so a pack cannot run code or read your data.

If you find a way for a pack to do more than that, **please do not open a public issue**. Use GitHub's private reporting ("Security" tab → "Report a vulnerability"), or email the maintainer through the address on their GitHub profile. A pack that is harmful, contains someone's personal data, or was copied without permission can be reported with the "A problem with a pack" issue form; it will be taken out quickly.
